Бэктест стратегии SMA (SBER, MOEX)
==================================

Что это: Python-бэктест стратегии «держать, когда цена выше SMA(50)».
Результат можно смотреть двумя способами: обычный режим с matplotlib
и настольное приложение с интерактивным HTML-графиком.


0. Быстрый старт (для тех, кто скачал архив с GitHub)
----------------------------------------------------
Нужен только Python 3.10+: https://www.python.org/downloads/
(при установке поставьте галочку "Add python.exe to PATH").

Распакуйте архив и дважды кликните:

    run.bat

Скрипт сам создаст виртуальное окружение, установит зависимости
(первый запуск — нужен интернет, пара минут) и откроет окно
«Бэктест стратегии SMA» с интерактивным графиком. При первом запуске
скрипт также скачает котировки SBER с MOEX.

Дальше запуск всегда одним двойным кликом по run.bat.


1. Обычный режим (консоль + matplotlib + HTML-график)
-----------------------------------------------------
Запуск из корня проекта:

    .\.venv\Scripts\Activate.ps1
    python main.py

Скрипт скачает котировки SBER с MOEX (при первом запуске; дальше
используется кэш data\SBER_daily.csv), посчитает бэктест, покажет
график капитала с текстовой сводкой и обновит два файла:
  - equity_curve.png — картинка графика;
  - web\chart_data.js — данные для интерактивного графика.

Интерактивный график: откройте двойным кликом web\chart.html
(работает локально, без сервера и интернета).


2. Настольное приложение Windows
--------------------------------
Само приложение в репозиторий не входит (собирается локально).
Соберите его командой из раздела 3, после этого запускать:

    dist\BacktestChart\BacktestChart.exe

Достаточно двойного клика по exe: приложение само считает бэктест
(кэш котировок встроен в сборку; если удалить data из сборки —
скачает котировки заново, нужен интернет) и покажет окно
«Бэктест стратегии SMA» с интерактивным графиком. Консоль Python
не требуется. Если расчёт завершится ошибкой, текст ошибки
отобразится в том же окне.

Внимание: переносить нужно всю папку dist\BacktestChart,
а не только exe — рядом с ним лежат необходимые библиотеки (_internal).


3. Пересборка приложения
------------------------
Запустите двойным кликом:

    build_exe.bat

Скрипт активирует .venv, очистит build\ и соберёт приложение
PyInstaller заново (результат — dist\BacktestChart\BacktestChart.exe).


4. Линейка на интерактивном графике
-----------------------------------
Кнопка «📏 Линейка» включает режим замера: кликните две точки
на графике — появится линия с подписью: изменение капитала в %,
число дней между точками и максимальная просадка на участке.
Повторные пары кликов добавляют новые измерения, «Очистить» убирает
все, Esc выходит из режима линейки. Колесо мыши — масштаб,
перетаскивание — прокрутка по времени.
